# 📋 ระบบเช็คงานค้าง

เว็บแอปสำหรับโรงเรียน ใช้ติดตาม **สถานะการส่งงาน** ของนักเรียน
**ไม่มีระบบคะแนนหรือเกรด** — เน้นให้เห็นชัดว่าใครค้างงานอะไร และงานไหนยังส่งทันหรือไม่

## สถานะการส่งงาน 5 แบบ

| สถานะ | ความหมาย | สี |
|---|---|---|
| ✅ ส่งแล้ว | ครูทำเครื่องหมายว่าได้รับงานแล้ว | เขียว |
| 🟡 ยังไม่ส่ง | ยังไม่ส่ง แต่ยังเหลือเวลาอีกมาก | เหลือง |
| ⏳ ใกล้กำหนดส่ง | เหลือเวลาไม่เกิน 3 วัน | เหลือง |
| ⛔ เลยกำหนดส่งแล้วแต่ยังรับอยู่ | เลยกำหนดแล้ว แต่ครูยังเปิดรับงานสาย | แดง |
| ❌ ปิดรับแล้ว | เลยกำหนดแล้ว และครูปิดรับงานแล้ว | ดำ |

สถานะทั้งหมดคำนวณอัตโนมัติจาก **กำหนดส่ง** + **ครูเปิด/ปิดรับงานสาย** + **ครูติ๊กว่าส่งแล้วหรือยัง**
งานที่ปิดรับแล้วจะยังอยู่ในจำนวน "ยังไม่ส่ง" และแสดงสถานะปิดรับแล้วในรายละเอียด แต่ไม่รวมในตัวเลขแจ้งเตือนงานค้างและไม่ทำให้การ์ดรายวิชาเป็นสีดำ
ครูสลับ "เปิด/ปิดรับงานสาย" ได้ทุกเมื่อด้วยปุ่มเดียว สถานะของนักเรียนทุกคนจะเปลี่ยนตามทันที

## ฝั่งนักเรียน (ล็อกอินด้วยเลขประจำตัวนักเรียน)
- หน้าแรกสรุป **งานทั้งหมด / ส่งแล้ว / ยังไม่ส่ง** ใน 3 ช่อง พร้อมแบนเนอร์แจ้งจำนวนงานที่ยังไม่ส่ง
- การ์ดรายวิชาไฮไลท์สีตามสถานะที่เร่งด่วนที่สุด พร้อม chip บอกว่าแต่ละสถานะมีกี่ชิ้น และเรียงวิชาที่เร่งด่วนขึ้นก่อน
- เข้าไปในวิชาจะเห็นกล่องสรุป 3 ช่อง และรายการ **"งานที่ต้องจัดการ"** แยกออกมาให้เห็นก่อนใคร
- **ตารางเรียนของห้องตัวเอง** — สร้างจากตารางสอนที่ครูบันทึกไว้โดยอัตโนมัติ เช่น ครูสมชายลงคาบสอนคณิต ม.2/1 วันจันทร์ คาบ 1 นักเรียนห้อง ม.2/1 จะเห็นวันจันทร์ คาบ 1 เป็นคณิตศาสตร์ (ครูสมชาย) ทันที ครูแก้ตารางเมื่อไหร่ ตารางเรียนนักเรียนเปลี่ยนตามทันที
- หน้ารายวิชาแสดงรายละเอียดงาน ตัวอย่างงาน ลิงก์แนบ สมาชิกกลุ่ม และหมายเหตุจากครูในหน้ารายการโดยตรง ถ้าตัวอย่างงานเป็น URL จะแสดงปุ่มเปิดลิงก์
- เวลาที่เหลือแสดงเป็นวันเต็ม ชั่วโมง และนาที โดยอัปเดตอัตโนมัติบนหน้ารายวิชาและรายละเอียดงาน เมื่อครบกำหนดจะแสดงเพียง "เลยกำหนดแล้ว"

## ลิงก์แนบ
ครูแนบลิงก์กับงานแต่ละชิ้นได้ (ใบงาน, Google Form ส่งงาน, วิดีโอ, เว็บอ้างอิง ฯลฯ)
พร้อมตั้ง "ข้อความแสดงแทนลิงก์" ให้อ่านเข้าใจง่าย เช่น *"ฟอร์มส่งงาน (อัปโหลด PDF ที่นี่)"*
ลิงก์จะแสดงเป็นปุ่มเด่นทั้งในรายการงาน หน้ารายละเอียด และฝั่งครู กดแล้วเปิดแท็บใหม่ได้ทันที

## ฝั่งคุณครู (ล็อกอินด้วยชื่อ + รหัสผ่าน)
- หน้าแรกแสดงรายวิชาที่สอน พร้อมทางเข้าจัดการงานและนักเรียนของแต่ละวิชา
- **ตารางสอนครู**: กดที่ช่องคาบ → ป็อปอัพให้เลือกวิชาที่สอน (วิชาที่ผูกห้องจะแสดงเป็นตัวเลือกรายห้อง เช่น คณิตศาสตร์ ม.2/1) เลือก 1 หรือ 2 คาบติดกัน แล้วบันทึก กดคาบที่มีวิชาอยู่แล้วเพื่อเปลี่ยนวิชา/ย้ายห้อง หรือลบ
- **สร้างวิชาที่สอน**: ระบุ **ระดับชั้น + ห้อง** (1 วิชาต่อ 1 ห้อง ถ้าสอนหลายห้องให้สร้างวิชาแยกทีละห้อง) นักเรียนทุกคนในห้องนั้นได้รับงานของวิชาโดยอัตโนมัติ ไม่ต้องเลือกนักเรียนเอง นักเรียนที่เพิ่ม/ย้ายห้อง/นำเข้าภายหลังจะเข้า-ออกวิชาให้เอง
- **จัดการนักเรียนในวิชาเสริม (หรือวิชาเดิมที่ยังไม่ผูกห้อง)**: ครูผู้สอนของวิชาเพิ่มนักเรียนเข้าวิชาเอง (เพิ่มทั้งห้อง หรือเลือกรายคนพร้อมกรองชั้น/ค้นหาชื่อ) และนำออกได้ ครูทุกคนที่สอนวิชาเดียวกันเห็นและแก้รายชื่อเดียวกัน
- **สั่งงานใหม่**: เลือกประเภทงานก่อน แล้วกรอกรายละเอียด ตัวอย่างงาน ลิงก์แนบ กำหนดส่ง และเลือกว่าจะรับงานสายหรือไม่; งานกลุ่มเลือกสุ่มสมาชิกหรือกำหนดหมายเลขกลุ่มของนักเรียนแต่ละคนและบันทึกพร้อมงานในครั้งเดียว
- ช่องวันที่ทั้งหมดกรอกแบบ **วัน/เดือน/ปี ค.ศ.** เช่น `14/10/2026` และกำหนดส่งใช้เวลาไทยแบบ 24 ชั่วโมง เช่น `14:30` การนับถอยหลังยึดเขตเวลาไทย (UTC+7)
- **ตารางเช็คสถานะ**: ตารางนักเรียน × งาน ติ๊ก "ส่งแล้ว" ได้ทันที แต่ละช่องมีสีพื้นหลังตามสถานะ บันทึกทีเดียวทั้งตาราง
- **หน้ารายละเอียดงาน**: เห็นรายชื่อนักเรียนเรียงตามความเร่งด่วน (คนที่ค้างและปิดรับแล้วขึ้นก่อน)
- **งานกลุ่ม**: จัดสมาชิกขณะสั่งงาน และดูสมาชิกหรือทำเครื่องหมาย "ส่งแล้ว" ทั้งกลุ่มในหน้ารายละเอียดงาน
- **ตารางสอน**: ตารางคงที่ **6 แถว x 9 คอลัมน์** — แถวคือวันจันทร์-ศุกร์ (ด้านซ้าย), คอลัมน์คือ คาบ 1-4 / พักเที่ยง / คาบ 5-8 (ด้านบน) ช่องที่ไม่มีคาบสอนจะเว้นว่าง คาบต่อเนื่อง 2 คาบจะรวมเป็นช่องเดียวกินพื้นที่ 2 ช่อง และช่องพักเที่ยงเป็นแถบตัวอักษรแนวตั้งยาวตลอดตาราง (คาบต่อเนื่องไม่สามารถคร่อมพักเที่ยงได้ ระบบจะปรับเป็น 1 คาบให้อัตโนมัติ) เลือกระดับชั้น (ม.1-ม.6) + ห้อง (1-2) และเลือก 1 คาบ หรือ 2 คาบติดกัน พร้อมเตือนเมื่อคาบชนกับครูคนอื่น
- ตัวนับ **คาบที่เหลือแยกตามวิชาและชั้น/ห้อง** (เริ่มนับจากวันเปิดเทอมหรือวันนี้จนถึงวันสิ้นสุดเทอม ไม่นับวันหยุด) ช่องตารางสอนแสดงจำนวนคาบทั้งคาบเดี่ยวและคาบต่อเนื่อง

## ฝั่งผู้ดูแลระบบ (ครูที่มีสิทธิ์ is_admin)
- **เพิ่มครู**: กรอกชื่อ-นามสกุล **ภาษาไทยและอังกฤษ** ระบบสร้างชื่อผู้ใช้ให้เองเป็น *ชื่อจริงภาษาอังกฤษ + อักษรแรกของนามสกุล* (เช่น Somchai Boonmee → `SomchaiB`, ถ้าซ้ำจะต่อเลข 2, 3 …) ครูที่เพิ่มใหม่เป็นครูทั่วไป ไม่ต้องเลือกสิทธิ์แอดมินหรือรายวิชา (ครูเพิ่มวิชาเองที่หน้าหลัก)
- จัดการ **ครู / นักเรียน / วิชาเสริม** (เพิ่มทีละคน หรือนำเข้าครู/นักเรียนจาก **Excel .xlsx / CSV**)
- กรองรายชื่อนักเรียนตาม **ระดับชั้น ม.1-ม.6** เลือกหลายคนเพื่อ **แก้ไขหรือลบพร้อมกัน** ได้
- **สร้างวิชาเสริม** (เช่น ชุมนุม) โดยกำหนดแค่ชื่อวิชา และ **ครูผู้สอน (ได้มากกว่า 1 คน)** — แอดมินไม่เพิ่มนักเรียนเอง ครูผู้สอนของวิชานั้นเข้าไปเพิ่มนักเรียนเอง; วิชาเสริมแก้ไข/ลบได้เฉพาะแอดมิน
- ฐานข้อมูลเก่าจะถูกอัปเกรดอัตโนมัติ (เพิ่มคอลัมน์ `is_elective`; วิชาเดิมที่มีครูตั้งแต่ 2 คนขึ้นไปจะถูกนับเป็นวิชาเสริม)
- ตั้ง **วันเปิดเทอมและวันสิ้นสุดเทอม** ของเทอมเดียวกัน (วันเปิดต้องมาก่อนวันสิ้นสุด; หากตั้งเทอมใหม่ให้เปลี่ยนทั้งสองวัน) และจัดการวันหยุดทั้งหมดในปฏิทิน คลิกวันที่ว่างหนึ่งวันหรือหลายวันเพื่อเพิ่ม หรือคลิกวันหยุดสีเขียวเพื่อแก้วันที่/รายละเอียดหรือลบ ระบบเติมวันหยุดราชการทั่วประเทศปีปัจจุบันและปีถัดไปอัตโนมัติเมื่อเปิดระบบหรือหน้าหลัก และเติมปีใหม่เมื่อปีเปลี่ยน วันที่ลบจะไม่ถูกเพิ่มกลับเมื่อเปิดระบบใหม่ วันหยุดเฉพาะพื้นที่/โรงเรียนและวันหยุดพิเศษที่ประกาศภายหลังสามารถเพิ่มเอง ปี 2569 ยึดวันที่ประกาศ ส่วนปีถัดไปใช้ข้อมูลจากแพ็กเกจ `holidays` ซึ่งเป็นค่าตั้งต้นตามปฏิทินไทย ควรตรวจทานเมื่อมีประกาศราชการเพิ่มเติม

## หมายเหตุด้านโค้ด (ย้ายตรรกะมาเป็น Python)
- กล่อง **คาบตอนนี้ / คาบต่อไป** คำนวณใน `models.py` (`period_box_state`) และแสดงผ่าน `templates/_period_box.html`; หน้าเว็บดึง `/period-box` มาอัปเดตทุก 30 วินาที (เดิมเป็น JavaScript ซ้ำกัน 2 ชุดในหน้านักเรียนและหน้าครู)
- **ปฏิทินวันหยุด** (แผงแอดมิน) สร้างใน `app.py` (`build_holiday_calendar`) ไม่ใช้ JavaScript แล้ว: ติ๊กวันที่ที่ต้องการ แล้วกดบันทึก; กดวันหยุดสีเขียวเพื่อแก้ไข/ลบ; วันที่ที่ติ๊กไว้จะถูกพาไปด้วยเมื่อเปลี่ยนเดือน
- ส่วนที่ยังเป็น JavaScript เพราะต้องตอบสนองทันทีโดยไม่โหลดหน้า: ป็อปอัพยืนยัน, นับถอยหลังกำหนดส่ง, ป็อปอัพเลือกคาบในตารางสอน, กรองรายชื่อนักเรียน, ตารางจัดกลุ่ม

## รูปแบบไฟล์นำเข้า

**ครู** — หัวคอลัมน์: `name,name_en,username,password,is_admin` (คอลัมน์ `password` เว้นว่างได้ ระบบสุ่มรหัสให้และแสดงครั้งเดียวหลังนำเข้า)
**นักเรียน** — หัวคอลัมน์: `student_id,name,grade_level,class_room`

รองรับทั้ง `.xlsx` และ `.csv` (ถ้าใช้ CSV ให้บันทึกแบบ UTF-8)
แถวที่ชื่อ/เลขประจำตัวซ้ำกับที่มีอยู่แล้วจะถูกข้ามอัตโนมัติ

## การปรับแต่งที่มักต้องทำต่อ

1. **เกณฑ์ "ใกล้กำหนดส่ง"** — ปัจจุบัน 3 วัน แก้ที่ค่า `SOON_DAYS` ใน `models.py`
2. **ข้อความ/สี/ไอคอนของสถานะ** — แก้ที่ `STATUS_META` ใน `models.py` ที่เดียว มีผลทั้งระบบ
3. **ความปลอดภัย**
   - รหัสผ่านครูเก็บเป็นแฮช (`werkzeug`) ไม่มีรหัสกลาง; ครูใหม่/รีเซ็ตรหัสผ่านจะได้รหัสสุ่มที่แสดงให้แอดมินเห็นครั้งเดียว ครูเปลี่ยนรหัสผ่านเองได้ที่เมนู "เปลี่ยนรหัสผ่าน"; ล็อกอินผิด 5 ครั้งใน 5 นาทีจะถูกบล็อกชั่วคราว
   - ตั้งค่าผ่านตัวแปรสภาพแวดล้อม: `SECRET_KEY` (ค่าสุ่มยาว ๆ), `ADMIN_PASSWORD` (รหัสแอดมินตอนสร้างฐานข้อมูลครั้งแรก), `FLASK_DEBUG=1` (เปิด debug เฉพาะตอนพัฒนา), `HOST` / `PORT` (ค่าเริ่มต้น 127.0.0.1:5000)
   - ฐานข้อมูลรุ่นเก่าที่เก็บรหัสผ่านเป็นข้อความธรรมดาจะถูกแปลงเป็นแฮชอัตโนมัติ (คงรหัสเดิมไว้ — ควรให้ครูเปลี่ยนรหัสหรือแอดมินรีเซ็ตให้)
   - ยังไม่มีการป้องกัน CSRF และนักเรียนล็อกอินด้วยเลขประจำตัวอย่างเดียว; เมื่อเปิดใช้จริงควรรันด้วย WSGI server (เช่น waitress บน Windows, gunicorn บน Linux) หลัง HTTPS
